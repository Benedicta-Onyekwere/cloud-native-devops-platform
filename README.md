# Cloud Native DevOps Platform

A production-inspired cloud-native platform demonstrating modern DevOps practices using Docker, Kubernetes, Terraform, Ansible, GitHub Actions, Prometheus, and Grafana.

## Project Overview

This project deploys a containerized web application and supporting services on Kubernetes using Infrastructure as Code and automation practices.

The goal is to build, deploy, monitor, and manage an application using a real-world DevOps workflow.

## Technologies

- Docker
- Kubernetes
- Terraform
- Ansible
- GitHub Actions
- AWS
- Azure
- Prometheus
- Grafana
- PostgreSQL
- Nginx
